# SSESA Website – Ekiti State University

## Overview
This is a modern, responsive website for the Social Science Education Students' Association (SSESA) at Ekiti State University, Ado-Ekiti. The site showcases the department's mission, programmes, events, and provides contact information.

## Features
- **Responsive Design**: Mobile-first approach with breakpoints for tablets and desktops
- **Modern UI**: Clean, professional design with smooth animations
- **Multi-page**: Home, About, and Contact pages
- **Accessible Navigation**: Mobile hamburger menu and desktop navigation
- **Contact Form**: Functional form with validation and success feedback
- **Event Calendar**: Display of upcoming SSESA events
- **FAQ Section**: Expandable FAQ items
- **SEO Optimized**: Proper semantic HTML and meta tags

## Customization

### Updating Content
- Edit HTML files directly for text content
- Update contact information in `contact.html` and footer sections
- Modify event dates in `index.html` events section

### Changing Colors
- Open `styles/main.css`
- Update CSS variables in `:root` section at the top

### Adding New Pages
1. Create new HTML file (e.g., `programmes.html`)
2. Copy the navigation and footer from existing pages
3. Update nav links to point to new page
